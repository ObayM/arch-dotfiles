## Requirements

- Arch Linux (the installer refuses to run anywhere without `pacman`)
- **Hyprland ≥ 0.55**: the Lua config API does not exist for versions before this!
- An AUR helper: `paru` or `yay`

Anything Else would be installed automatically from the install script, for this to work fine, try it on a fresh hyprland/arch setup!

## Install

```sh
git clone https://github.com/ObayM/arch-dotfiles ~/dotfiles
cd ~/dotfiles
./install.sh
```
