# arch-dotfiles

> Dotfiles for arch + hyperland



## Requirements

- Arch Linux
- **Hyprland >= 0.55**

## Install

```sh
git clone <repo-url> ~/dotfiles
cd ~/dotfiles
./install.sh
```
